# ⚡ ELECK — интернет-магазин электроники

**Технологии. Для вашей жизни.**

Eleck — учебный веб-проект магазина электроники и бытовой техники на Python и Django. Включает товарный каталог, галереи изображений, индивидуальные характеристики, цены и скидки, корзину и собственную панель управления ассортиментом.

## 🛒 Возможности магазина

| Возможность | Описание |
| --- | --- |
| Каталог | 8 категорий электроники и бытовой техники |
| Карточка товара | Название, модель, описание, галерея и технические характеристики |
| Цены и скидки | Автоматический расчёт стоимости со скидкой |
| Корзина | Добавление, изменение количества, удаление и итоговая стоимость |
| Авторизация | Собственная страница входа и выхода |

| Фотографии | Загрузка нескольких изображений JPEG, PNG или WebP |
| Интерфейс | Адаптивный тёмный дизайн: графит, серебро, зелёный и жёлтый |

## 🚀 Быстрый старт

### GitHub Codespaces

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/Denis-create-boop/django-project?quickstart=1)

В терминале выполните:

```bash
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py seed_catalog
python manage.py runserver 0.0.0.0:8000
```

Откройте порт **8000** через Open in Browser. Для учебной работы оставьте порт приватным.

### Локальный запуск

```bash
git clone https://github.com/Denis-create-boop/django-project.git
cd django-project
python -m venv .venv
```

Активируйте окружение: на Windows — `.venv\Scripts\activate`, на Linux/macOS — `source .venv/bin/activate`.

```bash
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py seed_catalog
python manage.py runserver
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000).

## 🔐 Управление магазином

Для новой базы создайте суперпользователя:

```bash
python manage.py createsuperuser
```

Если администратор уже существует, используйте его учётную запись или восстановите пароль командой `python manage.py changepassword ИМЯ`.

На сайте нажмите **Войти**, затем **Управление**. Обычные посетители могут просматривать каталог и пользоваться корзиной, но не изменять ассортимент. Проверка прав выполняется на сервере.

| Маршрут | Назначение |
| --- | --- |
| `/` | Главная страница и категории |
| `/about` | О магазине |
| `/login/` | Вход |
| `/manage/` | Собственная панель управления |
| `/cart/` | Корзина |
| `/admin/` | Стандартная административная панель Django |

## 💾 Данные и ограничения

- Перед миграциями рекомендуется сохранять резервную копию базы данных.
- Загруженные изображения находятся в локальной папке `media/`, исключённой из Git. Для переноса магазина сохраняйте базу и эту папку вместе.
- Команда `seed_catalog` предназначена для демонстрационного наполнения: названия моделей, цены и характеристики условные, изображения являются программно созданными иллюстрациями.
- Оформление заказов, платежи и доставка не реализованы.
- Настройки предназначены для разработки. Перед публичным развёртыванием необходимо отключить DEBUG, настроить отдельный секретный ключ, допустимые хосты, HTTPS и безопасное хранение данных.
